🔍 Хто смикає WMI
WmiPrvSE.exe сам нічого не робить — він виконує WMI-запити інших програм (MSI Center, ASUS-агенти, антивірус, і наш монітор теж). Провайдер ETW Microsoft-Windows-WMI-Activity записує клієнта кожного запиту. Разово, за кліком, без драйверів; потрібні права адміністратора.
🩺 Перевірка системи
Усі перевірки лише читають — нічого не вимикається, не чиститься й не «оптимізується». Рішення завжди за тобою.
⏱ Затримки системи
Потік із високим пріоритетом просить розбудити його рівно через 1 мс і засікає, наскільки Windows запізнилась. Паралельно знімаються зрізи системи, щоб зіставити затримки з тим, що саме в ці моменти відбувалось — і сказати, драйвер це чи програма.
Міряй тоді, коли проблема відчувається. Довший замір ловить рідкісні шпички краще.

🔬 Назвати драйвер поіменно

Якщо замір вище показав, що винні драйвери — цей крок скаже, який саме файл (умовно nvlddmkm.sys). Windows коротко записує події ядра власними засобами, а монітор зіставляє адреси процедур зі списком завантажених драйверів.
Без встановлення драйверів, без вимкнення Secure Boot і без конфліктів з анти-чітами. Потрібні лише права адміністратора.
Почни з «Перевірити можливості» — це кілька секунд і одразу скаже, чи спрацює трасування, замість того щоб чекати марно.
📋 Буфер обміну
Буфер обміну один на всю систему. Кожну зміну Windows розсилає всім, хто підписався, і кожен читає вміст собі. З текстом непомітно, а знімок екрана — це десятки мегабайтів, які копіюються стільки разів, скільки таких програм.
Найкорисніше — натиснути саме тоді, коли гальмує: тоді видно, хто тримає буфер.
Розмір даних за замовчуванням не вимірюється: щоб його дізнатися, треба змусити програму-джерело віддати вміст просто зараз — а якщо вона гальмує, підвисає буфер усієї системи. Вмикай, лише коли справді потрібно.

🚀 Що стартує разом із Windows

Записи не видаляються — лише вимикаються тим самим штатним механізмом, яким користується Диспетчер задач. Увімкнути назад можна будь-коли одним кліком. Критичні служби Windows захищені й не змінюються взагалі.
